# Documentation

## Pour reprendre le projet

1. Lire `../AGENTS.md`, puis `../RELAIS_IA.md` : règles de travail et état actuel.
2. Utiliser `../studio/runtime-manifest.json` pour relier les 46 scripts actifs aux instances Roblox Studio.
3. Ouvrir uniquement le guide de référence utile au changement. Les guides ci-dessous décrivent l'état fonctionnel et les preuves disponibles ; vérifier leur portée et leurs limites.

## Guides de référence

- Monde : `reference/ZONES.md`, `reference/NAVIGATION_ZOMBIES.md`
- Combat : `reference/ZOMBIES_COMBAT.md`, `reference/CAPACITES.md`, `reference/TIRS_A_LA_TETE.md`
- Déplacements : `reference/MOUVEMENTS.md`
- Économie et progression : `reference/EXPEDITIONS.md`, `reference/CAISSES.md`, `reference/ADMIN_PANEL.md`
- Armes : `reference/ARMES_A_FEU.md`
- Interface : `reference/UI_MOBILE.md`

## Notes historiques

`historique/` contient des analyses, idées et plans anciens. Ils aident à comprendre l'intention, mais ne prouvent pas qu'une fonctionnalité existe aujourd'hui. Pour l'état réel, privilégier `RELAIS_IA.md`, les guides de référence et les sources `studio/` comparées à Studio.

## Sources du jeu

`../studio/` contient les sources Luau, `runtime-manifest.json`, les archives et les harnais QA. Les constructeurs ponctuels, archives et tests ne sont pas des scripts de démarrage. `../assets/` contient les ressources graphiques.
